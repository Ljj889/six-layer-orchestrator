# real-source-repro · 真实源码复现 + 接缝替身模板

> **版本**：v1.0 · 2026-09-30 · 来源：伴学 P0 实战 A-4（蒸馏）+ 引擎层研讨 D-04 收敛
> **本条在框架里的位置**：rule 79 家族（渲染端静默失效 / 产物断言）**只保留一句引用**，**主载体 = 本文件**。
> **一句话**：**接缝可以替身，通道不可以 mock。** 替身合法与否，判据不是"能不能造出来"，而是"**被测对象是我们的逻辑，还是平台的行为**"。

---

## 一、判定线（先分类，再动手）

| 对象 | 例子 | 能不能替身 | 理由 |
|---|---|---|---|
| **我们定义的接缝（seam）** | `dir-io`、`compress` 注入点、自建 `IoC` 接口、`fetchLike` 抽象 | ✅ **可以**（合法替身） | 验的是**我们的逻辑**（路径拼接、压缩策略、错误分支），平台行为不在被测范围内 |
| **平台通道（channel）** | `plus.android` 设备 API、`ipcRenderer.invoke`、`net.Socket`、`fs` 原生写、HTTP 传输层、真机硬件 | ❌ **不可以** | 替身一旦造出来，**被测通道本身被伪造** → 100% 假绿（伴学实测：`Files.copy` 不报错但产出 0 字节） |

**判定问句**：把这段代码原样搬到另一台机器，**行为会不会变**？
- 不会变（纯逻辑） → 接缝，可替身。
- 会变（依赖设备/平台/内核/网络） → 通道，**必须真机/真实往返**。

## 二、接缝替身模板（书面理由必填）

> **硬性**：任何替身都必须连同下面这张卡一起交付。**缺"它是接缝不是通道"的书面理由 → 该替身视为非法**（= 假绿风险未排除）。

```yaml
# seam-stub-card.yaml — 接缝替身登记卡
stub_name: makeFsIo                  # 替身模块/函数名
file: 验证/s1/run-s1-importer-test.mjs
replaces: dir-io                     # 被替身的东西
classification: seam                 # seam | channel（只允许 seam）
why_seam_not_channel: >
  被替身对象是"我们定义的目录读写抽象"（dir-io），不是平台 API：
  真实实现内部才调用 fs/native。替身替换的是我们自己的适配层，
  验的是 importer 的路径拼接/去重/冲突命名逻辑。
  —— 平台行为（真机文件系统语义）不在本测试的被测范围内。
tested_logic:                        # 这个测试到底在验什么（必须写具体）
  - 同秒双拍 → 自动补号 _r2 / _r3
  - 暂存路径规范化
not_covered:                         # 诚实声明：它不保证什么
  - 真机文件系统权限/容量
  - 跨设备 file URI 语义
real_channel_verified_by: 真机 S3 验收（photo-import 场景）
```

## 三、真实源码复现（rule 41 / 82 的手法）

**问题**：把逻辑"复刻一份"来测 —— 复刻通过 ≠ 原逻辑正确（复刻时已经把 bug 抄没了）。

**做法**（成本从低到高）：

1. **转译真实源文件片段**：用 `esbuild` / `tsc` 只编译被测源文件（或其中的私有函数）为可 require 的临时模块，**不重写逻辑**。
   ```bash
   npx esbuild src/foo.ts --bundle --format=cjs --outfile=.tmp/foo.cjs --loader:.ts=ts
   ```
2. **提取私有函数**：源文件里 `export` 不出的私有函数 → 用转译后的模块 + 测试专用 `__test__` 导出，或最小 patch（只加导出、不动逻辑）。
3. **喂真实数据**：真实日志、真实 DB 行、真实报错栈、真实产物字节 —— **不要造"干净"合成数据**（rule 43：合成数据盖不住真实噪声）。
4. **对照实验**：一次只改一个变量，记 `[排错检查点]`（rule 81）。

**反例（禁止）**：把源文件里的算法**手抄**进测试文件里再断言 —— 这是"复刻自测"，通过也不构成证据。

## 四、引擎自测的同一硬线（v3.21.0 · D-04 补）

**引擎自己的自测同样不得 mock 平台通道** —— 直接封死"用 mock 冒充自测"。

- ✅ **允许**：**录制重放**（L0 探针把真实响应原文存成 fixture，自测重放）。**录制重放不是 mock** —— 它测的是**解析逻辑**，fixture 是**真实通道的真实输出**。
- ❌ **禁止**：手写假的 `socket.recv` / 假 HTTP 响应 / 假设备返回值来冒充"通道自测"。
- 判据：**fixture 是否来自一次真实的、记录在案的往返**（含来源元数据：时间 / 端点 / 模型 / 请求参数 / 原始字节）。

> 这也是 L0 探针的硬门：**无 fixture → 不许动 L2**（R-03：手写 SSE 的边界无网不可真验，唯一合规自测办法是录制重放）。
